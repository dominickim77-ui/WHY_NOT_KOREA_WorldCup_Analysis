# Source data not bundled

The uploaded project did **not** contain the original FIFA annual CSV archive. The original Colab notebook extracts it to `/content/worldcup` and refers to filenames such as `FIFA - 2002.csv`.

Before adding a file, record its **exact source URL**, license, download timestamp, original filename, SHA-256, and schema. Do not substitute an unrelated Kaggle dataset merely because it has a similar title.

Public uploads are permitted only after licensing and sensitive-data checks.
