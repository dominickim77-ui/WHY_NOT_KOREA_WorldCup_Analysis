# RAG 구현 범위

Python 표준 라이브러리만 사용한다. `scripts/rag_qa.py`는 매 실행 시 CSV를 읽어 대한민국·연도·지표 조건으로 검색하고 검색된 값만 문장으로 출력한다. 근거 ID는 국가·기간·열로 구성되며 파일 SHA-256과 물리적 CSV 행 번호(헤더 1행)를 제공한다. 전체 기록은 country_summary.csv, 연도별 기록은 korea_summary.csv에서 조회한다.

이는 구조화 검색 + 추출형 답변 구현이다. 임베딩, 벡터 DB, 외부 LLM 호출은 포함하지 않는다. 의미 검색·다국가 비교·복수 연도 비교·원인 분석·예측은 지원하지 않는다. 지원하지 않는 질문은 확인 불가를 반환한다. 질문 해석은 제한된 키워드 방식이므로 모든 자연어 표현에 대한 완전한 의도 판별을 보장하지 않는다.

테스트는 숫자, 인용 ID, 실제 CSV 행·열과 값의 일치, 파일 해시, 연도별 순위, 범위 밖·전술·선수·비지원 항목을 확인한다. 기존 설계의 자유 생성 모델에 대한 허위 인용 탐지 테스트는 LLM이 추가될 때 별도로 구현해야 한다. 이번 테스트는 CSV의 외부 사실 정확성을 재검증한 것이 아니다.

스크린샷은 실제 함수 실행 JSON을 HTML로 렌더링한 Edge headless 브라우저 캡처다. 원본 JSON과 테스트 로그는 rag_evidence/에 있다. 분석 스크립트는 재실행하지 않아 기존 그래프를 보존했다.
